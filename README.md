# Neon Drift

A neon 3D endless runner built with React, Vite, and Three.js. Change lanes, jump gaps, slide under barriers, collect shards, and keep your combo alive as the speed increases.

## Run locally

Requires Node.js 20 or newer. Install dependencies with `npm install`, then start the development server with `npm run dev`.

Create a production build with `npm run build`; run the TypeScript check with `npm run typecheck`.

## Controls

- Left / Right arrows or A / D — change lanes
- Up arrow / Space or W — jump
- Down arrow or S — slide
- P / Escape — pause or resume
- Touch buttons are available on small screens.

Your best score is stored locally in the browser.
